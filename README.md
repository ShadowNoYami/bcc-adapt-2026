# BCC Adapt

Интерактивная презентация независимой конкурсной разработки Жамбылского политехнического высшего колледжа для V регионального ITU HACKATHON-2026.

[Открыть сайт](https://shadownoyami.github.io/bcc-adapt-2026/)

## Показ для жюри

На главной странице нажмите «Презентация». Стрелки и пробел переключают разделы. Кнопки со стрелками работают мышью и касанием. Escape возвращает к обычной прокрутке. Оглавление открывается кнопкой меню. Если браузер ограничивает полноэкранный API, показ занимает доступное окно.

В разделе «Путь пользователя» настройте масштаб, контраст, кнопки и плотность интерфейса. В симуляторе перевода выберите получателя и сумму, затем нажмите «Проверить перевод». Новый получатель или сумма от 50 000 ₸ включают пятисекундную паузу. Для завершения удерживайте кнопку 1,5 секунды пальцем, мышью, пробелом или Enter. Раннее отпускание отменяет подтверждение.

Пример голосовой команды подставляет подготовленную фразу. Для озвучки суммы используется речевой синтез браузера при наличии русского голоса. Сайт работает на демонстрационных данных без банковских API. Запись микрофона не требуется.

## Локальный запуск

Требуется Node.js 22.12+ или совместимая более новая версия и npm.

```sh
npm ci
npm run dev
```

Проверка TypeScript и сборка для публикации:

```sh
npm run build
npm run preview
```

Vite сохраняет готовый статический сайт в `dist/`. Относительная база `./` поддерживает размещение в подпапке. Шрифты, логотипы и скрипты загружаются с того же сайта.

## Публикация

В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. При изменениях в `main` workflow `.github/workflows/pages.yml` установит зависимости по lock-файлу, проверит типы, соберёт сайт и опубликует `dist/`. Для ручного запуска откройте **Actions → Deploy BCC Adapt → Run workflow → main → Run workflow**. URL доступен в окружении `github-pages` после успешного деплоя.

## Содержание и источники

Все десять разделов опираются на презентацию BCC Adapt. Оценки бюджета и эффекта — сценарные показатели кейса. В экономической модели годовой эффект равен 18,5 + 24,0 = 42,5 млн ₸. Регулятор меняет долю этого эффекта. Месяц окупаемости — первый целый месяц, к концу которого накопленный эффект покрывает 5,3 млн ₸. Эксплуатационные расходы в прогноз не включены.

Показатели 19/19 и шесть экранов относятся к описанному в презентации Flutter MVP. Веб-симуляторы реализованы отдельно на React, TypeScript, Vite, Tailwind CSS, Motion и Lucide React.

Эмблема колледжа извлечена из предоставленной версии презентации. Фирменный знак банка взят с [официального сайта Банк ЦентрКредит](https://www.bcc.kz/themes/bcc/assets/images/logo-w.svg). Проект имеет статус независимой конкурсной разработки.
